# Blocksmith CIA packaging

Turns the already-built homebrew (`blocksmith.elf` / `blocksmith.3dsx` at the
project root, produced by `make`) into an installable `blocksmith.cia`.

## Inputs

| File | What it is |
|---|---|
| `../blocksmith.elf` | The built game. `make` produces this; this step does not. |
| `../blocksmith.3dsx` | The Homebrew Launcher build. Checked for as a build-completeness sanity check; not itself fed to makerom. |
| `blocksmith.rsf` | The makerom spec: title, product code, unique ID (`0xB10CC`), memory/filesystem permissions. Adapted from the working sibling project's `modelkit.rsf` - see the comments inside for exactly what changed and why. |
| `../gfx/icon.png` | 48x48 Home Menu icon. Generated by `../tools/make_banner.py` - re-run that script to regenerate it. |
| `../gfx/banner.png` | 256x128 Home Menu banner artwork. Same script. |

`../tools/make_cia.sh` generates the banner's audio track at build time by
calling `../tools/make_banner_audio.py`, so it is not a checked-in asset. That
script synthesises the chime from scratch - four notes, three sine partials
each, a short noise strike per onset - using only the standard library and a
hand-written LCG seeded with the title's own unique ID, so a re-run is
byte-identical. Nothing is sampled and nothing is downloaded, the same rule
every other generated asset on this project follows.

## Running it

From a devkitPro MSYS2 bash prompt, after `make` has already built the game:

```
tools/make_cia.sh
```

It will not run `make` for you - if `blocksmith.elf` or `blocksmith.3dsx`
is missing, it stops and tells you to build first. It also refuses to
produce a half-built CIA silently: any missing tool or failed step aborts
the script with a clear message instead of continuing.

## What a good run looks like

Console output ending with:

```
make_cia.sh: built C:/.../mc/blocksmith.cia (NNNNNN bytes)
```

and a `blocksmith.cia` file at the project root, a few hundred KB to a few
MB depending on the current build (the base game with the current asset
set: see the log for the measured size from the last real run). Intermediate
files (`*-cia.smdh`, `*.bnr`, `silence.wav`) are left in `cia/build/` for
inspection; they are build output, safe to delete and regenerate.

Installing and booting the resulting CIA is not verified by this script or
by this step - that needs a real console or Citra/Azahar and is a manual
playtest.
