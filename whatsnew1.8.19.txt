# Release notes shown on the 3DS top screen before the update downloads.
#
# Two sections, both optional, one item per line. Plain English, no markdown: this is read
# by a player on a 400 px screen, not by a developer. A leading "- " is optional.
#
# Keep every item under 95 characters. Wrapping onto a second display line is automatic and
# fine, but the ITEM cap bites first and is a different number: app/whatsnew.h's
# WHATSNEW_ITEM_CHARS is 96 bytes INCLUDING the terminator, so a 96th character is cut, its
# last three replaced with "...", and the whole file flagged truncated. Earlier copies of
# this header said only "long lines wrap on their own", which is true of the layout and not
# of the parse, and this file was first written to 169 characters on the strength of it.
# app/version_history_test.c re-parses every baked note, so the cut fails the build rather
# than reaching a player.

[fixes]
Water you placed on a server could vanish when you rejoined while the world was still loading.
Hitting an animal was silent. Hits and kills now make a sound, from the animal itself.

[features]
Footsteps sound different on stone, wood, dirt and grass instead of all sounding the same.
Breaking and placing a block now sound like the material, not one sound for everything.
The freeze on startup is still not fixed, and this build does not claim to fix it.
If it happens, look in the blocksmith folder on your SD card for two files it leaves.
stage.txt says how far the game got. cmdhang.bin says what the graphics chip was doing.
Either of those two files is worth far more than a description of what you saw.
