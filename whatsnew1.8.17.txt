# Release notes shown on the 3DS top screen before the update downloads.
#
# Two sections, both optional, one item per line. Plain English, no markdown: this is read
# by a player on a 400 px screen, not by a developer. A leading "- " is optional.
#
# Long lines wrap on their own, so write a sentence rather than fighting the width.

[fixes]
Found and fixed two real bugs behind the new-world freeze. Not proven to be the fix itself.
The safety net for a stalled GPU now actually stops it instead of freezing anyway.
Breaking a furnace gives you back what was inside it instead of destroying it.
The updater no longer reads its certificate file mid-check, and says why if it still fails.
Its GitHub error was never your console's fault - it could not load its own certificates.

[features]
A splash when you climb out of water, and a wake trailing you while you swim.
The water-entry splash appears on the surface now, not underwater where you cannot see it.
Dirt takes its biome's colour, so exposed dirt in a jungle or desert no longer reads as plains.
A New 3DS now starts at a wider view distance and meshes chunks faster. Old 3DS is unchanged.
The world's block lookup is smaller and faster. Same world, less work per chunk.
The crash report now records which processor core each thread actually ran on.
If the game freezes again, check blocksmith/stage.txt on the SD card - it now says where.
